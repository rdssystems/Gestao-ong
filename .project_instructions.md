# Gestão ONG - Sistema Administrativo

## Overview
Complete admin management system for NGOs (ONGs) built with Next.js 14, Prisma, PostgreSQL. Interface entirely in Brazilian Portuguese.

## Visual Style
- **Theme**: Teal/emerald color palette (primary HSL: 166 72% 40%)
- **Fonts**: DM Sans (body), Plus Jakarta Sans (headings), JetBrains Mono (numbers)
- **Design**: Clean, professional, sidebar navigation, cards with shadows, motion animations

## Architecture
- **Route group**: `(authenticated)` for all protected pages with shared sidebar layout
- **Auth**: NextAuth.js v4 with CredentialsProvider, email/password, JWT sessions
- **Database**: PostgreSQL via Prisma ORM

## Data Models
- **User**: Admin accounts for login
- **TipoCurso**: Course categories/tags (nome, descricao, cor)
- **Aluno**: Students with soft delete (ativo flag), full personal data, address, interests
- **AlunoInteresse**: M2M between Aluno and TipoCurso (student interests)
- **Curso**: Courses linked to TipoCurso, with vagas control, status, scheduling
- **Matricula**: Enrollment linking Aluno to Curso, with vacancy management

## Key Features
- Soft delete for students (ativo/inativo toggle, never hard delete)
- Vacancy control: increment on enrollment, decrement on cancellation
- Duplicate enrollment prevention (unique constraint alunoId+cursoId)
- Interest-based student suggestions when creating enrollments
- Dashboard with animated counters, top courses, recent students

## Pages
- `/login` - Login page
- `/dashboard` - Stats overview
- `/alunos` - Student CRUD with filters/pagination
- `/tipos-curso` - Course type CRUD (dialog-based)
- `/cursos` - Course CRUD with filters/pagination
- `/matriculas` - Enrollment management with status changes

## Seed Data
- 6 course types, 8 students, 6 courses, 13 enrollments pre-seeded
